# 安卓工作区适配

日期：2026-11-03。设计咨询：同项目「Gemini」会话 `01a19bcf-4f8f-78f2-9c79-3dc56ac44d9e`，本轮 `01a19f6c-85b0-73a2-aa69-58d59b0ec3e8`。Gemini 读取用户截图和源码、提供方案；Codex 实现和验证。

## 已实现

- 工作区头部按组件实际宽度和系统字号切换：紧凑布局将配置名、状态与操作分行；宽屏保留单行操作。名称单行省略、状态最多两行，不再被按钮挤成竖排。
- 窄屏标签单行横向滚动，选中标签自动进入视野；保留全部六个入口及原有切换回调。
- 用户后续指定：Android/iOS 任务总览与 Windows 一样直接显示立即排队、等待、编辑三个按钮，移除三点菜单；保留原有禁用条件。移动端每个按钮使用互不重叠的 48×48 点击区域，常规宽度在右侧水平排列；窄屏或大字体导致文字空间不足时，整组按钮移至卡片下一行靠右，并同步增加卡片高度。桌面保留原有紧凑按钮，移除错误的 90px 固定操作区。
- 总览与任务目录按面板有效宽度和文字缩放计算列数，每列以 300px 为基准；单列兜底。卡片随大字体增高，目录按钮及开关采用触控尺寸，时间标签不再使用固定文本高度。
- 主导航随软键盘调整内容高度。高度不足时工作区整体可滚动，允许滚走头部并访问任务列表。主页原有 SafeArea 与 NavigationBar 的系统边距处理继续复用。
- Android/iOS 禁用桌面任务拖拽复制，避免与滚动冲突；配置手柄排序仍可使用。

## 对 Gemini 建议的调整

采用其头部分行、单行标签、按钮尺寸修复方向。系统字号继续完整保留，未套用其建议的 1.25 倍上限；三个图标采用独立点击区域，避免热区重叠。断点继续基于现有工作区的真实可用宽度计算，未强制在 860px 放入三栏。
